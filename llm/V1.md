# v1 reference

Facts about v1 (see [GLOSSARY.md](../GLOSSARY.md)), collected 2026-11-11. v1 is the balance reference for v2 and
a hint for commander and AI support. Read this when tuning balance (PLAN step 2), adding AI parity (step 4) or
commander support (step 5).

## Where it is

`C:\Program Files (x86)\Steam\steamapps\common\Forts\data\mods\iuw\` is an old local copy. It is a read-only
reference: edit and deploy only this repository. (`data\mods\iuw2\` next to it is an old copy of v2; its
`dump\weapons.lua` and `dump\projectiles.lua` are dumps of in-game weapon and projectile data, including DLC ones.)

## Shape

- 64 levels: `_cannon2` .. `_cannon64`, level 1 is the base weapon. Level weapons are named `_<savename><level>`.
- Python generators in `pregen_scripts\**\pregen_*.py` wrote fixed numbers into `weapons\<name>\_<name><level>.lua`.
  Those generated files hold the actual v1 values per level and are the easiest thing to parse.
- Only the last tier of each chain has levels (minigun, sniper2, mortar2, missile2, ...), plus third-party weapons
  (Tanya's, Big Friendly Cannon, AA Laser, Cannon Cannon), which v2 leaves out.

## Formulas (the same for every weapon; `L` = level)

| Value | v1 rule |
|---|---|
| Projectile damage, impact, splash damage, splash force, penetration damage, ray damage | `base · (1 + 0.125 · (L - 1))` |
| Splash radius | `base · (1 + 0.125 · √(L - 1))` |
| EMP radius / duration | `base · (1 + 0.2 · √(L - 1))` / `base · (1 + 0.0625 · (L - 1))` |
| Reload time | `base · (1 - L/128)`, never below `base / 2` |
| Fire cost (energy, metal) | each level: `previous · (1 + 1/64) + flat`, with a flat amount per weapon (cannon 300 / 5, minigun 30 / 2, sniper 20 / 0.3, 20mm 250 / 4, ...) |
| Beams (laser, firebeam) | duration and energy fire cost `base · (1 + 0.1 · (L - 1))` |
| Fire speed | plus a flat amount per level and weapon (cannon 111, minigun 450, sniper 250, shotgun 1000, rocket 25) |
| Spread | falls linearly to half at the top level |
| Upgrade price to level `L` | `U · (1 + L/6)`, metal and energy each with their own `U` (table below) |
| Build cost of level `L` | previous level's build cost + that upgrade price; repair cost is 75 % of it |
| Upgrade time (`BuildTimeComplete` of the level weapon) | the weapon's reload time (table below) |

Total metal spent to reach level `L` is `base + U · Σ(1 + l/6)` for `l = 2..L`, so it grows with the square of the level.

## Commander support

v1 shipped conditional sub-mods inside the mod: `mods\commander-<x>\...` is only active while commander `<x>` is
active, and `mods\commander-<x>\mods\1369514837\weapons\<w>\<file>.lua` overlays the mod's own level files by
Workshop id. Example (Scattershot, `_buzzsaw10.lua`): `RoundsEachBurst = RoundsEachBurst + 2`.

- Covered: Scattershot, Seep, Shockenaugh, Buster, Moonshine, Overdrive, Hurricane, Firebird, Armourdillo;
  Warthog was unfinished (`mods\todo\`).
- `commander.lua` scripts list level weapons by name (e.g. Scattershot's `IUW_WeaponsToMark` for the focus icon).
- Armourdillo's armour-piercing minigun had its own levels (`common\weapons\minigunAP\`).
- `UpgradeNumber = Level` on level weapons was "for overdrive adjustment" (Overdrive: `commander-da-overclocker`).

## AI support (`ai\ai.lua`)

For every level: `ShootableProjectile["_<projectile><level>"] = true` for projectiles that can be shot down, and for
anti-air weapons `data.AntiAirErrorStdDev`, `data.AntiAirOpenDoor`, `data.AntiAirFireProbability` and
`AntiAirFireProbabilityHumanAssist` entries per level weapon.
